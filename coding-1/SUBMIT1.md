# Coding Assignment 1: What To Submit

Submit the source files that you modified for Coding Assignment 1, primarily `src/Lexer.cpp` and `src/Parser.cpp`. Do not submit build directories, executables, LLVM-generated files, or other temporary files. Your submitted code should compile with the provided TinyLang starter project without requiring changes to the supplied interfaces or other project files.

You must also submit a `tests/` directory containing **your own TinyLang test programs** used to test your lexer and parser. Your tests should include both valid programs and intentionally invalid programs, and should exercise more than the example cases provided with the assignment. Include a short `README.md` inside the `tests/` directory describing what each test is intended to check and whether it should succeed or produce a lexical/syntax error. Your test cases are part of the assignment grade and should demonstrate that you considered both normal cases and edge cases.
